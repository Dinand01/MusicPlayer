# Music Player Documentation

This documentation tracks the current state of the MusicPlayer repository as it evolves over time.

## How to Contribute

When changes are made to the application, update the relevant documentation files:

- **ARCHITECTURE.md** - Update architectural decisions, components, and data flow when major structural changes occur
- **FEATURES.md** - Add new features and update feature lists
- **TECHNOLOGY-STACK.md** - Add new libraries, dependencies, or technology changes
- **HOW-IT-WORKS.md** - Detail new modules, APIs, or workflows
- **API.md** - Document new endpoints, classes, or interfaces
- **FILES.md** - Update file structure when new files are added or replaced

## Document Types

- `.md` - Markdown documentation files
- `assets/` - Diagrams and images (generated using mermaid.js where possible)
- `CHANGELOG.md` - Track changes made to the codebase

## Current State

This repository is a .NET/C# music player with a React frontend that:
- Loads and streams large music libraries
- Hosts music servers or connects as clients
- Supports YouTube video streaming
- Provides internet radio support
- Allows file copying between folders
